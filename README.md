# Comfort Zone to Success Animation

A visual representation of the journey from comfort zone to success, illustrating the concept of breaking through different zones (Comfort, Fear, Learning, Growth) to reach success.

## Features
- Animated concentric circles representing different zones
- Triangle animation breaking through each zone
- Particle effects when breaking through each barrier
- Success celebration animation
- Responsive design that works on different screen sizes
- Automatic restart of animation

## How to Use
1. Clone this repository
2. Open the `index.html` file in your browser
3. Watch the animation play automatically
